# RAINY Татагч · Windows

Монгол хэлтэй Chrome өргөтгөл болон компьютерт ажиллах таталтын туслах програм.

YouTube, Facebook, Instagram, X, TikTok, yt-dlp дэмждэг бусад сайтын нийтэд нээлттэй бичлэгийн холбоосоор ажиллахаар боловсруулсан. Сайт бүрийн бүх бичлэг, хаалттай нийтлэл, шууд дамжуулалт, DRM контентыг дэмжинэ гэсэн баталгаа байхгүй. Бодит сайтуудын таталтыг энэ хүргэлтийн орчинд туршаагүй.

## 1. Суулгах — эхний удаа

1. ZIP файлыг **бүрэн задална**. ZIP дотроос INSTALL.cmd-ийг шууд ажиллуулахгүй.
2. **INSTALL.cmd** файлыг хоёр дарж ажиллуулна. Administrator эрхээр ажиллуулах шаардлагагүй. Хамаарал татахад интернэт хэрэгтэй.
3. Суулгац Python 3.11+, FFmpeg/ffprobe, Deno-г шалгаж, дутууг winget-ээр суулгахыг оролдоно. yt-dlp болон түүний default хамаарлуудыг тусдаа Python орчинд суулгана.
4. Суулгац амжилттай бол хавтас нээгдэнэ. Chrome-ийн хаягийн мөрөнд **chrome://extensions** гэж бичиж орно.
5. Баруун дээд талын **Developer mode**-ыг асаана.
6. **Load unpacked** дараад дараах хавтсыг сонгоно:

   `%LOCALAPPDATA%\RAINYDownloader\extension`

   Хавтас сонгох цонхны хаягийн мөрөнд дээрх замыг хуулж оруулж болно.
7. Өргөтгөлийн ID **fpkmjpbhnffggibaenfhnacakkcpfbmc** байгааг шалгана.
8. Chrome-оо бүх цонхтой нь хааж дахин нээнэ. Өргөтгөлийг puzzle дүрсний цэснээс **Pin** дарж бэхэлнэ.
9. Видео байгаа хуудсаас RAINY дүрсийг дарна. **Татахад бэлэн** гэсэн төлөв гарвал холбоотой байна.

Энэ багц нь Chrome Web Store-д нийтлэгдсэн өргөтгөл эсвэл гарын үсэгтэй EXE биш. Chrome өргөтгөлийг эхний удаа дээрх аргаар гараар ачаална. Өргөтгөлийг ачаалсан суулгалтын хавтсыг устгахгүй.

## 2. Бичлэг татах

1. Видео байгаа хуудас дээр өргөтгөлийг дарна. Холбоос автоматаар орно. Шаардлагатай бол өөр холбоос оруулна.
2. Холбоосны хажуугийн **→** товчоор гарчиг, боломжит чанарыг шалгаж болно.
3. **Видео · MP4** эсвэл **Аудио · MP3** сонгоно. Видео бол дээд чанар сонгоно.
4. **Татах** дарна. Тохиргоог санаж дараалалд нэмнэ.
5. **Таталтууд** хэсэгт явц, хурд, үлдсэн хугацаа харагдана. **Цуцлах**, **Дахин татах**, **Хавтас нээх** үйлдлүүд бий.

Өргөтгөлийн жижиг цонх хаагдсан ч туслах програмын таталт үргэлжилнэ. Компьютер унтрах, сүлжээ тасрах үед бүх таталт тасралтгүй үргэлжилнэ гэж амлахгүй. Тасарсан ажилд **Дахин татах** ашиглана. Хөдөлгүүр боломжтой хэсгээсээ үргэлжлүүлнэ.

MP4 нь H.264/MP4-т тохирох эх форматыг сонгоно. Эх видеод хүссэн чанар/кодек байхгүй бол бага чанар эсвэл боломжгүй гэсэн алдаа гарч болно. 4K сонголт бүх видеог 4K болгохгүй. MP3-г 192 kbps зорилтот битрейтаар хөрвүүлнэ; эх аудионы чанарыг сайжруулахгүй.

## 3. Автомат таталт

- Тохиргоо **⚙** → хавтасны бүтэн зам, үндсэн формат, чанараа хадгална.
- **Өргөтгөлийг дарахад шууд дараалалд нэмэх** сонголтыг асаавал видео хуудаснаас өргөтгөлийг дарахад холбоосыг шалгаж өмнөх тохиргоогоор таталт эхэлнэ.
- Нэг ажил дуусмагц дараагийн ажил автоматаар эхэлнэ.
- **Олон холбоосоор татах** хэсэгт нэг мөрөнд нэг холбоос оруулна (100 хүртэл). Шалгалт хугацаа авч болно. Шалгаж дуусах хүртэл энэ цонхыг нээлттэй байлгана; аль хэдийн дараалалд орсон таталт үргэлжилнэ.
- Playlist болон олон бичлэгтэй нийтлэлийн эхний 100 хүртэл бичлэгийг шалгана. Үндсэн холбоос хэсэгт оруулаад татах бичлэгүүдээ тусад нь сонгоно.
- Таталтын дэлгэцийн хэмжээ хязгаартай. Идэвхтэй дарааллын эхний хэсэг болон сүүлийн түүх харагдана; харагдаагүй ажлууд дискэнд хадгалагдсан хэвээр байна.

## 4. Хавтас болон өгөгдөл

Үндсэн хавтас: хэрэглэгчийн Downloads доторх **RAINY**.

Туслах програм, Python орчин, Chrome extension: `%LOCALAPPDATA%\RAINYDownloader`.

Түүх, тохиргоо: `%LOCALAPPDATA%\RAINYDownloader\data\queue.db`.

Суулгасан Python багцын бодит хувилбарууд: `%LOCALAPPDATA%\RAINYDownloader\installed-versions.txt`.

Татсан видео хэрэглэгчийн компьютерт хадгалагдана. Нууц үг, browser cookie автоматаар авахгүй. Таталт хийхэд хэрэглэгчийн төхөөрөмж тухайн сайттай болон хөдөлгүүрийн шаардлагатай эх сурвалжтай шууд холбогдоно. Тусдаа RAINY сервер рүү бичлэг явуулахгүй.

## 5. Алдаа гарвал

**“Суулгац шаардлагатай”** — INSTALL.cmd-ийг дахин ажиллуулж, зөв extension хавтас ачаалсан эсэхээ шалгана. Chrome-оо бүрэн хааж дахин нээнэ.

**ID тохирохгүй** — manifest.json дахь key-г өөрчилсөн эсвэл өөр extension ачаалсан байж болно. Анхны extension хавтсыг ачаална. Хөгжүүлэгч өөр ID хэрэглэх бол `windows/install.ps1 -ExtensionId <32 тэмдэгт>` ашиглаж болно.

**winget олдсонгүй** — Microsoft Store-оос App Installer суулгана. Эсвэл Python, FFmpeg, Deno-г албан ёсны эх сурвалжаас суулгаж PATH-д оруулаад Windows терминалаа дахин нээнэ.

**FFmpeg / Deno суусангүй** — дараах командыг PowerShell-д ажиллуулаад шинээр нээсэн терминалаас INSTALL.cmd-ийг дахин ажиллуулна. Байгууллагын компьютерт суулгалтын бодлогоор хаагдаж болно.

```powershell
winget install --exact --id Python.Python.3.12
winget install --exact --id Gyan.FFmpeg
winget install --exact --id DenoLand.Deno
```

**Таталт ажиллахгүй, sign in / unsupported URL / private video** — нийтэд нээлттэй зөв холбоос эсэхийг шалгана. Энэ хувилбар нэвтрэх cookie автоматаар дамжуулахгүй. DRM хамгаалалтыг тойрохгүй. Сайт өөрчлөгдвөл шинэ yt-dlp шаардлагатай байж болно.

**Формат олдсонгүй** — чанараа бууруулах эсвэл аудиогоор турших. MP4-т тохирох эх формат байхгүй байж болно.

**Суулгац дахин ажиллуулахад түгжээтэй** — таталтаа дуусгах/цуцлах, Chrome-оо хаах, хоёр минут хүлээгээд дахин ажиллуулна.

**Хурд/үлдсэн хугацаа харагдахгүй** — эх сервер хэмжээгээ зарлаагүй эсвэл хөдөлгүүр нэгтгэж байгаа үед тодорхой хувь/хугацаа байхгүй байж болно.

## 6. Шинэчлэх, устгах

Шинэчлэхдээ бүх таталтаа дуусгаж эсвэл цуцалж, Chrome-оо хааж хоёр минутын дараа шинэ багцын INSTALL.cmd-ийг ажиллуулна. Дараа нь chrome://extensions дээр Reload дарна. Нэг суулгах зам ашиглавал ID тогтвортой байна.

Устгахдаа **UNINSTALL.cmd**-ийг ажиллуулаад chrome://extensions дээр RAINY өргөтгөлийг **Remove** дарж устгана. Татсан файлууд, түүх, тохиргоо болон нийтлэг Python/FFmpeg/Deno хэрэгслүүдийг хадгална. Түүхээ бүрэн арилгах шаардлагатай бол туслах програм зогссон үед `data` хавтсыг өөрөө устгаж болно.

## 7. Хөгжүүлэгчийн шалгалт

```bash
python -m unittest discover -s tests -v
npm test
python -m compileall -q host
```

Node нь зөвхөн хөгжүүлэлт/туршилтад хэрэгтэй; хэрэглэгчийн таталтын хөдөлгүүрт шаардлагагүй. Тестүүд бодит видео сайтуудыг татаж шалгасан гэсэн үг биш. **VALIDATION.md**-ээс туршсан хүрээг харна уу.
