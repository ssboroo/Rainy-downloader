# RAINY Татагч — Windows Chrome өргөтгөлийн загвар

Огноо: 2026-10-15. Төлөв: хэрэгжүүлэхийн өмнөх хяналтын загвар.

## Зорилго
Windows 10/11 дээр Chrome-оос видео, аудиог хялбар татах. Бүх интерфэйс, суулгах заавар, алдааны тайлбар монгол хэлтэй байна. YouTube, Facebook, Instagram, X, TikTok болон yt-dlp дэмждэг бусад сайтуудыг зорилтот хүрээнд оруулна. Сайт бүрийн бодит дэмжлэгийг туршилтын үр дүнгээр ялгаж мэдээлнэ; бүх сайт, бүх видеог татна гэсэн амлалт өгөхгүй.

## Хэрэглэх урсгал ба дүрслэл
1. Өргөтгөлийг нээхэд идэвхтэй табын холбоос харагдана. Холбоосыг гараар сольж болно.
2. «Шалгах» дарахад гарчиг, зураг, үргэлжлэх хугацаа, боломжит форматыг үзүүлнэ.
3. Видео эсвэл аудио, чанараа сонгоод том «Татах» товч дарна.
4. Өргөтгөлийн жижиг цонх хаагдсан ч туслах програм таталтыг үргэлжлүүлнэ.
5. «Таталтууд» хэсэгт хувь, хурд, үлдсэн хугацаа, цуцлах болон дууссан файлын байршлыг нээх үйлдэл байна.

Цайвар дэвсгэр, цэнхэр үндсэн өнгө, том уншихад хялбар үсэг, энгийн дүрс, зөөлөн сүүдэртэй карт ашиглана. Үндсэн цонхонд холбоос, формат, чанар, татах товч, идэвхтэй таталтууд харагдана. Нарийн тохиргоо тусдаа хуудсанд байна. Гарын товчлуур болон дэлгэц уншигчаар хэрэглэх боломжтой байна.

## Автомат ажиллагаа
Сонгосон хавтас, формат, чанарыг санана. «Нэг товшилтоор татах» горим идэвхжүүлбэл хэрэглэгчийн үйлдлээр одоогийн холбоосыг өмнөх тохиргоогоор шалгаж дараалалд оруулна. Нэг таталт дуусмагц дараагийнх эхэлнэ. Давхардсан идэвхтэй холбоосыг нэмж татахгүй. Олон холбоосыг мөр мөрөөр оруулж болно. Хуудас нээх төдийд болон clipboard-оос далд таталт эхлүүлэхгүй. Playlist болон олон бичлэгтэй нийтлэлийг бүхэлд нь татахаас өмнө тоо, сонголт үзүүлнэ.

## Бүтэц
Chrome Manifest V3 өргөтгөл нь интерфэйс, табын холбоос, тохиргоог хариуцна. Native Messaging холболт Windows туслах програмтай харилцана. Туслах програм нь yt-dlp, FFmpeg/ffprobe, шаардлагатай JavaScript runtime ашиглан мэдээлэл шалгах, татах, формат нэгтгэх, аудио гаргах, дараалал удирдах үүрэгтэй. Таталтын төлөв, түүх дискэнд хадгалагдана. Chrome дахин нээгдэхэд явцыг дахин авна. Компьютер унтарсан таталтыг автоматаар амжилттай гэж тэмдэглэхгүй; үргэлжлүүлэх боломжтой хэсгийг хөдөлгүүрийн дэмжлэгийн хүрээнд үргэлжлүүлнэ.

## Формат ба найдвартай байдал
Видео: MP4 зорилтот гаралт; чанар нь тухайн эх үүсвэрт байгаа хэмжээгээр. MP4-т тохирох кодек байхгүй үед чимээгүй өргөтгөл солихгүй, боломжит хувилбарыг тайлбарлана. Аудио: MP3, сонгосон чанарт хувиргана; эхээс илүү чанартай боллоо гэж тайлбарлахгүй. Нэгэн зэрэг нэг таталт ажиллана. Сүлжээний түр алдаанд хязгаартай дахин оролдоно. Цуцлахад зөвхөн тухайн ажлын процессуудыг зогсооно.

## Хандалт ба хамгаалалт
Зөвхөн HTTP/HTTPS холбоос хүлээн авна. Командыг shell мөр болгон залгахгүй, аргументын жагсаалтаар ажиллуулна. Native host нь зөвшөөрсөн extension ID-гаар хязгаарлагдана. Нууц үг, браузерын cookie-г автоматаар уншихгүй. Эхний хувилбар нийтэд нээлттэй видео дээр төвлөрнө; нэвтрэх шаардлагатай видеод ойлгомжтой мэдэгдэл өгнө. DRM хамгаалалтыг тойрохгүй. Файлын нэр болон хавтасны замыг шалгана. Видео өгөгдөл гуравдагч таталтын серверээр дамжихгүй.

## Суулгац ба хүргэлт
Өргөтгөлийн эх код, Windows туслах програм, суулгах/устгах скрипт, хамаарлын хувилбар ба лицензийн мэдээлэл, монгол зааврыг ZIP багцаар хүргэнэ. Эхний суулгалт Chrome-ийн Developer mode → Load unpacked аргаар хийгдэнэ. Энэ нь гарын үсэгтэй нэг даралтын EXE суулгац эсвэл Chrome Web Store-д нийтэлсэн бүтээгдэхүүн биш. Хамаарлууд татагдаж суусан эсэхийг шалгана; амжилтгүй бол суулгац дууссан гэж мэдээлэхгүй.

## Шалгах шалгуур
Холбоосын шалгалт, тохиргоо хадгалалт, дараалал, давхардал, цуцлалт, Native Messaging мессеж, алдааны хөрвүүлэлтийг автомат туршилтаар шалгана. Бодит Windows Chrome дээр суулгах, MP4/MP3 татах, popup хаасан үед үргэлжлэх, татсан файл нээгдэхийг тусад нь шалгана. Зорилтот таван платформын зөвшөөрөгдсөн туршилтын холбоосоор боломжит хэмжээнд туршина. Windows болон бодит сайт дээр туршаагүй хэсгийг хүргэлтийн тайланд тодорхой тэмдэглэнэ.
